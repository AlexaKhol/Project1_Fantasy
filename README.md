# Project1_Fantasy
## 📖Контекст данных
«Секреты Темнолесья» — это ролевая онлайн-игра, где основным источником дохода является продажа внутриигровой валюты «райские лепестки» и эпических предметов.
Команда разработки планирует привлекать платящих игроков и продвигать покупки. Цель данного проекта — провести исследовательский анализ данных (EDA) и ответить на вопросы бизнеса:

Монетизация: Какую долю составляют платящие игроки и есть ли зависимость доли платящих от расы персонажа?

Поведение: Как игроки покупают эпические предметы (какова их средняя стоимость, есть ли аномалии, какие предметы самые популярные)?

Ad-hoc гипотеза: Правда ли, что игра за некоторые расы сложнее и требует большего количества покупок?

## 📊Основные результаты
В ходе анализа были выявлены следующие инсайты:

Стабильность конверсии: Доля платящих игроков по всей игре составляет примерно 17%. Выбор расы персонажа практически не влияет на вероятность перехода в статус платящего игрока.

Асимметрия трат: Средний чек (526 лепестков) в 7 раз превышает медианный (75 лепестков). Топ-10% игроков приносят основную долю выручки, что указывает на важность их удержания.

Концентрация спроса: около 98% всех покупок приходится всего на два эпических предмета — Book of Legends и Bag of Holding. Остальные 143 предмета обладают низкой популярностью.

Баланс рас: Гипотеза о разной сложности прохождения игры за разные расы не подтвердилась. Базовые метрики вовлеченности и конверсии у всех рас стабильны.

## Структура данных (кратко)
*Таблицы хранятся в схеме 'fantasy'*
| Название | Что хранит |
| :--- | :--- |
| `users` | Информация об игроках |
| `events` | Информация о внутриигровых покупках с использованием игровой валюты «райские лепестки» |
| `skills` | Информация о легендарных умениях игрового персонажа |
| `race` | Информация о расе игрового персонажа |
| `classes` | Информация о классе игрового персонажа |
| `country` | Информация о стране регистрации игрока |
| `items` | Информация об эпических предметах, которые покупаются за игровую валюту «райские лепестки» |

## 🛠️Инструменты и структура проекта
Анализ выполнен на языке SQL с использованием PostgreSQL (в среде DBeaver).
- /Scripts/: Папка с SQL-скриптом (для удобства есть общий скрипт и скрипты по каждому запросу);
- /reports/: Отчёт по полученнным результатам;
- Файл README_detailed_instructions.md - углубленная информация по проекту и коду.
